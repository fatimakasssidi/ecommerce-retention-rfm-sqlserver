# Data Source and Data Policy

Project: E-commerce Customer Retention & RFM (SQL Server)

This project uses **one public dataset**. Raw data is **never committed** to this repository. The files are downloaded manually (a Kaggle login is required) into `data/raw/`, which is ignored by Git, and only a small synthetic sample lives in `data/sample/`.

---

## 1. Source

### REES46 eCommerce Behavior Data (Kaggle)

| Item | Value |

## 2. Data policy

1. **No raw data in Git.** `data/raw/` is ignored. Anyone who clones the repository downloads the files from Kaggle and accepts the dataset terms themselves.
2. **Synthetic sample only.** The license is "Data files © Original Authors", so the data is **not redistributed**, not even a part of it. `data/sample/` holds a few thousand rows generated by `scripts/generate_sample.ps1` with the same structure and issues as the real data, and **no real rows**. It is used for tests and CI.
3. **Attribution.** The README credits the dataset, its creator (Michael Kechinov), the Open CDP project and the license. Published results (README, report, screenshots) show aggregated numbers, not lists of raw rows.
4. **Code and data are licensed separately.** The code in this repository is MIT licensed (see `LICENSE`). The dataset keeps its own license, listed above.
5. **No personal data.** The dataset uses anonymous identifiers. The project makes no attempt to identify individuals, and no real contact details are added or invented.
6. **Secrets.** Credentials live in `.env` (ignored). `.env.example` holds placeholders only.

## 3. Notes on the data

- The two files cover about two months (October and November 2019). The exact first and last event dates are confirmed in E3-07.
- The Kaggle page describes the dataset as 7 months (October 2019 to April 2020) and 285 million events, while the download contains these two files. **Decision (2026-10-29): the project uses only these two files.** No additional months are downloaded.
- The late-November period includes Black Friday.
- Prices have no stated currency.
